# Recuperação (obrigatória) de P-Wev
## Digital Project - Site de Arquitetos

Recriação do protótipo [Website of Architects (Figma)](https://www.figma.com/community/file/891374608655348853/website-of-architects-free-website) usando **React + Vite + React Router**.

## Tecnologias

- React
- Vite
- React-Router
- CSS (responsivo)

## Rotas

| Rota | Página |
|---|---|
| `/` | Home |
| `/galeria` | Galeria de fotos |
| `/projetos` | Lista de projetos |
| `/projetos/:id` | Detalhes do projeto (rota dinâmica) |
| `/sobre` | Sobre a empresa |
| `/contato` | Contato |

## Como rodar

```bash
npm install
npm run dev
```

O site abrirá em `http://localhost:5173`.
